
# 💻 DSAWithJava

Welcome to **DSAWithJava** — a structured and comprehensive collection of Java programs covering everything from **Java fundamentals** to advanced **Data Structures and Algorithms**.

This repository is designed to help learners, job seekers, and competitive programmers strengthen their DSA skills using Java, with well-documented solutions, problem statements, and explanations for each topic.

---

## 🚀 Why Use This Repository?

- ✅ Covers **Java Basics to Advanced DSA**
- ✅ Clean directory-wise topic separation
- ✅ Each sub-topic includes:
  - 📄 `README.md` with explanation
  - 💻 Well-written `.java` code
- ✅ Ideal for:
  - Interview preparation
  - Competitive coding
  - Academic understanding
  - Self-paced DSA learning

---

## 🧭 Repository Structure

Each folder represents a major DSA topic or concept and contains:
- One or more `.java` source files
- A topic-wise `README.md` file with:
  - Problem descriptions
  - Intuition and approach
  - Code overview and complexity analysis

```
DSAWithJava/
├── JavaBasics/         # Variables, Loops, Conditionals, etc.
├── OOPs/               # Classes, Objects, Inheritance, Polymorphism
├── Arrays/             # 1D & 2D Arrays, Prefix Sum, Sliding Window
├── Strings/            # StringBuilder, Palindromes, Anagrams
├── Recursion/          # Backtracking, Subsets, Permutations
├── Sorting/            # Quick Sort, Merge Sort, Bubble, etc.
├── Searching/          # Binary Search, Search in Rotated Array
├── LinkedLists/        # Singly, Doubly, Reversal, Cycle Detection
├── Stacks/             # Stack using Array/LL, Infix to Postfix
├── Queues/             # Circular Queue, Deque, Queue using Stack
├── Trees/              # Binary Tree, BST, Traversals, Diameter
├── Heaps/              # Max/Min Heap, Priority Queue
├── Tries/              # Word Break, Prefix Search, Longest Word
├── Graphs/             # BFS, DFS, Dijkstra, Topo Sort, Kosaraju
├── DynamicProgramming/ # Knapsack, LIS, LCS, Memoization & Tabulation
├── Greedy/             # Activity Selection, Job Scheduling
├── BitManipulation/    # Bitwise Operations, Power of 2, XOR Tricks
└── README.md           # ← You are here!
```

## 📌 Sample Highlight: Tries

The `Tries/` directory includes:

- Word Break using Trie  
- Prefix Search using `startsWith()`

- Finding the longest word built one char at a time

Each with:
- Problem statement
- Code walkthrough
- Time & space complexity analysis
